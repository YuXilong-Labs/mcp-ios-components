# Implementation Checklist（防重复造轮子）

## 开发前
- [ ] 需求已拆为能力清单（网络/UI/路由/图片/存储/埋点）
- [ ] 每类能力至少执行 3 轮 `search_component`
- [ ] 至少 1 次中文关键词 + 1 次英文关键词 + 1 次类名关键词
- [ ] 对候选组件执行 `get_component_api`
- [ ] 对关键类执行 `get_class_detail` 或 `read_source`

## 开发中
- [ ] 代码仅使用已确认组件 API
- [ ] 未新增平行基础封装（如自建网络层/图片缓存）
- [ ] 关键错误路径有处理（失败/超时/空数据）

## 开发后
- [ ] 自检：是否可进一步替换为现有组件 API
- [ ] 输出检索证据（关键词、命中组件、文件/类）
- [ ] 输出选型理由（为何选 A，不选 B）
